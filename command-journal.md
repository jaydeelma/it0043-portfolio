1. git init
This command initializes Git in my project folder so I can start tracking changes

Area: Repository

2. git add
This command selects the file changes I want to include in my next commit

Area:Staging Area

3. git commit
This command saves a snapshot of the staged changes in my local Git repository

Area: Repository

4. git remote add origin
This command connects my local Git repository to a remote repository on GitHub using the name origin

Area: Repository configuration

 5. git push
This command uploads my committed changes to the remote repository on GitHub
Area: Remote Repository

 6. git status
This command shows me which files are new, modified, staged, or not yet committed

Area:Working Directory and Staging Area

7. git log
This command displays the history of commits made in my repository

Area:Repository
